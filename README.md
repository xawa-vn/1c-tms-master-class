# Интерактивный мастер-класс по 1С:TMS

Next.js-презентация для проведения мастер-класса по компетенции «Специалист по контролю качества транспортных логистических процессов».

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Возможности

- 6 пошаговых экранов по исходной инструкции;
- маршрут занятия общей длительностью 10 минут;
- скриншоты интерфейса 1С:TMS с увеличением;
- интерактивные чек-листы для участников;
- именная памятная карточка участника с экспортом в PNG;
- управление стрелками клавиатуры;
- адаптивная версия для телефона и проектора.

## Публикация на GitHub Pages

Проект настроен для репозитория `1c-tms-master-class`. После отправки ветки `main` workflow `.github/workflows/deploy-pages.yml` автоматически собирает и публикует сайт.
